# FPS Boost

Booster automatique pour tous vos jeux sur Windows.

- Détecte automatiquement le jeu lancé (Steam, Epic, Riot, Xbox, Ubisoft, EA, GOG, Rockstar, Battle.net + 60 jeux connus)
- Pendant la partie : alimentation performances maximales, timer système 0,5 ms, nettoyage de la RAM, priorité Haute au jeu, applis d'arrière-plan en priorité basse
- Compteur de FPS en direct
- Remet tout en place quand le jeu se ferme
- Mises à jour automatiques
